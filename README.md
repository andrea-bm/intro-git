# Mi primer repositorio

En este proyecto he aprendido los siguientes comandos:

- `git clone`
- `git log`, con los modificadores `--oneline` `--all`
- `git checkout`
- `git diff`
- `git add .`
- `git commit -m "mensaje"`
- `git remote`, incluyendo `get-url` y `set-url`
- `git merge`, para arreglar una cosita
- `git push`
